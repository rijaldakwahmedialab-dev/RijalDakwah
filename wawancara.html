Sinkronisasi Cloud Antar-Perangkat

Hubungkan nilai & catatan langsung ke Google Spreadsheet

Status Sinkronisasi Multi-Device: Belum Terhubung

Dengan menghubungkan Google Apps Script, semua pewawancara di perangkat masing-masing (HP, Laptop, Tablet) dapat melihat dan menyimpan nilai secara bersamaan ke Google Sheets secara real-time.

Endpoint resmi otomatis terpasang bawaan tanpa perlu input manual.

Tautan Otomatis untuk Seluruh Panitia:

Kirim link ini ke grup WA/Telegram panitia agar HP/laptop panitia lain otomatis tersambung tanpa perlu input URL lagi:

  1. Buka spreadsheet database private baru: Buka Google Sheets Private (ID: 1aI3lHKD...VWt0)
  2. Klik menu Ekstensi (Extensions) > Apps Script.
  3. Hapus tulisan bawaan di editor, lalu salin dan tempel kode di bawah ini.
  4. Klik tombol Simpan (ikon disket).
  5. Klik tombol biru Terapkan (Deploy) > Penerapan baru (New deployment).
  6. Pilih jenis Aplikasi web (Web app):
    • Jalankan sebagai: Saya (Me)
    • Yang memiliki akses: Siapa saja (Anyone)
  7. Klik Terapkan, lalu salin URL Web App yang diberikan dan tempelkan pada kotak di atas.
